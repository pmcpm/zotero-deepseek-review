# 需求确认与证据整理

## 只询问尚未确定的事项

先读取用户消息、已有任务配置、待补全文清单和阶段状态。已给出的数值、路径和偏好直接复用；有冲突时针对冲突询问。使用可用的 ask clarification 工具，按主题分组，每轮至多三个短问题；无工具时以同等简短问题确认。

写作前应明确：

- 题目、研究语境、写作范围、读者，以及作者提供的框架、方法、实验和研究结果。
- 正文字数上限与统计口径；参考文献目标数量；中英文文献的大致比例，以及数量和比例分别属于目标还是硬限制。
- 引用样式与版次。选项优先提供“GB/T 7714-2015 顺序编码制上标”和“APA 7 作者年份”；工具的自由输入接收其他样式、期刊要求或样例。
- 参考文献是否隐藏 DOI，以及中文条目是否采用“中文著录项（英文著录项）”。这两项独立确认。
- 普通 URL 沿用 skill 的默认文献类型策略：正式出版物省略，必要网络资源保留。用户或投稿模板提出特殊要求时记录覆盖；这与 DOI 显示选项分别处理。
- 检索时间范围、来源限制、语言、Zotero 目标分类、补全文目录、Word 输出位置、版式模板和额外禁用表达。

缺失任务数值时请求用户填写，避免沿用其他论文的字数、数量或比例。可先进行与这些数值无关的环境探测和探索检索。默认字数采用 Microsoft Word 字数，包含小节标题，排除文内引文和文末参考文献；其他口径由用户指定后同步写入提示词和审查设置。

## 检索与选择

调用 `nature-academic-search` 时读取它的 manifest、always_load 核心和本次需要的 multi-source-search / citation-verification 工作流。按研究对象、任务、方法和评价路径组合中英文检索式，保存来源及检索日期。普通主题跨期刊检索。Nature/CNS 限制来自用户的明确要求，届时加载 `nature-citation` 并执行其边界。

按 DOI、规范化标题、作者年份依次判断重复；DOI 缺失或有冲突时核对全文和出版版本。预印本与正式发表版本建立关系并选择实际引用版本。先搜索已有 Zotero 条目再新增，避免把同一文献的中英文题名建立为两条。

维护稳定证据 ID。新增条目追加 ID，移出核心集的 ID 保留历史，后续恢复时继续使用原 ID。文内稳定 ID 与最终 Zotero 编号分离。

## 两次题录核对

导入前核对出版社/期刊页面、DOI 注册信息和全文首页：文献类型、全部作者及顺序、题名、刊名、年份、卷期、起止页或文章号、DOI、URL。记录每个更正的来源和证据位置。来源冲突保留原始记录和选择理由；缺失字段保持缺失，直到取得可靠来源。

导入后读取实际 Zotero item 数据并逐项比较：作者 family/given 与 literal/团体作者的映射、年份、卷期、文章号、题名中的特殊字符、DOI、分类归属和附件 parent key。检测差异后修正题录并再次读回。修改已有条目前取得快照，合并此次已核实字段；发现并发变化时重读并处理冲突。

“期刊[J]”“书籍[M]”、姓名缩写和最终标点属于 CSL 输出规则，保持结构化题录字段清洁。DOI 显示偏好只控制输出样式，Zotero 的 DOI 数据保留。

## 证据卡与全文补充

每篇保存完整题录、稳定 ID、Zotero key/URI、公开来源、全文路径及哈希、研究对象、数据、方法、主要发现、可支撑论点、证据位置及核验状态。摘要可用于筛选和摘要层级描述；涉及具体方法、数值和发现的句子对应全文页码、节号或明确段落。Codex 核对句子的对象、方法和结论范围。

任何来源获取受阻时，依次查找出版社、机构库和作者公开版本。仍需用户下载则一次列出题名、作者、年份、DOI/链接、建议文件名及确切下载目录，写入待补清单。继续处理其他可获取文献；依赖缺失全文的证据确认、论证和写作保持等待状态。

用户补齐后检查文件可读性、首页题录与出版版本，计算文件哈希并绑定原 ID。重复文件合并，错配文件明确指出。处理完成后更新待补清单，从原阶段继续，不重建 ID 或重复导入。

## 从文献到行文逻辑

以研究路径比较组织段落，国内外研究按主题交织。每节确定比较维度、共同点、差异、证据组合和篇幅预算，再输出结构供写作模型使用。结论属于文献综合还是作者研究结果应清楚区分；具体算法、数据规模、成效和创新点以作者材料为来源。无法支撑的具体结论从写作证据包移出并记录原因。
